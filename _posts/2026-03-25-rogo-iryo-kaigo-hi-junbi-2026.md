「老後にいくら医療費・介護費がかかるか不安」という声をよく聞きます。実際のところ、**生涯で支払う医療費・介護費は数百万〜数千万円**にのぼる可能性があります。

しかし、正しく準備すれば怖くありません。この記事では老後の医療費・介護費の実態と、今からできる準備方法を徹底解説します。

---

## 老後の医療費・介護費の現実

### 一生涯の医療費の平均

厚生労働省のデータによれば、日本人が一生涯に支払う医療費の自己負担額（保険適用分の1〜3割）は**平均約700〜900万円**と試算されています。

ただし、自己負担には「高額療養費制度」があるため、実際の負担はこれより少なくなります。

### 介護費用の現実

公益財団法人生命保険文化センターの調査では：

| 項目 | 金額 |
|------|------|
| 介護期間の平均 | **約5年1ヶ月** |
| 月々の介護費用平均 | **約8.3万円** |
| 初期費用（入院・改修等） | **約74万円** |
| **合計（平均）** | **約600〜700万円** |

ただしこれは「平均」の話。認知症や寝たきりになった場合、10年以上・1,000万円超になるケースも珍しくありません。

## 高額療養費制度で医療費の上限を知る

医療費が高額になっても、**高額療養費制度**があるため無制限に払い続ける必要はありません。

### 2026年の自己負担上限額（月額・70歳未満）

| 区分 | 年収の目安 | 上限額（月） |
|------|-----------|------------|
| 区分ア | 年収1,160万円超 | 252,600円＋α |
| 区分イ | 年収770〜1,160万円 | 167,400円＋α |
| **区分ウ（一般）** | **年収370〜770万円** | **80,100円＋α** |
| 区分エ | 年収370万円以下 | 57,600円 |
| 区分オ（住民税非課税） | — | 35,400円 |

**例**: 年収500万円の方が1ヶ月100万円の医療費がかかった場合
→ 自己負担は約**8〜9万円**（残りは健康保険が負担）

### 「多数回該当」でさらに安くなる

同一世帯で12ヶ月以内に3回以上高額療養費が支給された場合、4回目から**自己負担上限額が下がります**（区分ウの場合4.4万円に）。

---

## 70歳以上の医療費負担

70歳になると、自己負担割合と上限額が変わります。

### 70〜74歳の自己負担割合
- 一般（現役並み所得以外）: **2割**
- 現役並み所得（年収約383万円以上）: 3割

### 75歳以上（後期高齢者医療制度）
- 一般: **1割**（2022年以降、一定所得者は2割）
- 現役並み所得: 3割

## 介護保険の仕組みと費用負担

介護が必要になると「介護保険」が使えます。介護保険は**40歳から保険料を払い**、65歳以降に要介護認定を受ければサービスを利用できます。

### 要介護度別の支給限度額（月額）

| 要介護度 | 支給限度額（月） | 自己負担1割の場合 |
|---------|--------------|----------------|
| 要支援1 | 50,320円 | 5,032円 |
| 要支援2 | 105,310円 | 10,531円 |
| 要介護1 | 167,650円 | 16,765円 |
| 要介護2 | 197,050円 | 19,705円 |
| 要介護3 | 270,480円 | 27,048円 |
| 要介護4 | 309,380円 | 30,938円 |
| 要介護5 | 362,170円 | 36,217円 |

**ただし**、これは在宅サービスの限度額です。施設に入所すると別途費用がかかります。

### 老人ホーム・介護施設の月額費用の目安

| 施設の種類 | 月額の目安 |
|-----------|-----------|
| 特別養護老人ホーム（特養） | 5〜15万円 |
| 介護老人保健施設（老健） | 8〜15万円 |
| 有料老人ホーム（介護型） | 15〜30万円 |
| グループホーム | 10〜20万円 |
| サービス付き高齢者向け住宅 | 10〜25万円 |

## 高額介護サービス費制度（知らないと損！）

介護保険サービスの月の自己負担が一定額を超えると、超えた分が**戻ってくる制度**があります。

### 2026年の自己負担上限額（月額）

| 対象者 | 上限額（月） |
|--------|------------|
| 一般（住民税課税世帯） | **44,400円** |
| 世帯全員が住民税非課税 | **24,600円** |
| 本人の年金収入等80万円以下 | **15,000円** |

申請は市区町村の窓口で行います。**自動的に計算されないので要注意**。

## 老後の医療費・介護費に備える3つの方法

### 方法1: 医療保険・介護保険（民間）の活用

民間の医療保険・介護保険は、公的保険でカバーしきれない部分を補います。

**選ぶポイント**:
- 入院日額: 5,000〜10,000円/日
- 手術給付金の有無
- 三大疾病（がん・心筋梗塞・脳卒中）特約
- 先進医療特約（高額な自由診療をカバー）

**見直しのタイミング**: 結婚・出産・転職・定年退職

> **保険の見直しを無料相談する → [保険の窓口（来店無料）](https://保険の窓口リンクをA8.netから取得)**

### 方法2: iDeCo（個人型確定拠出年金）で老後資金を積み立てながら節税

iDeCoは老後資金の積み立てと節税が同時にできる最強の制度です。

- 掛け金が**全額所得控除**（節税効果）
- 運用益が**非課税**
- 受け取り時も**退職所得控除 or 公的年金等控除**が使える

医療費・介護費の備えにも使える老後資金を、節税しながら積み立てられます。

> **iDeCo口座開設は → [SBI証券（手数料最安水準）](https://SBI証券リンクをA8.netから取得) / [楽天証券](https://楽天証券リンクをA8.netから取得)**

### 方法3: 新NISAで積み立て投資（医療費・介護費専用ファンドを設定）

新NISAのつみたて投資枠で、「老後医療費・介護費専用」の積み立てファンドを設定するのも有効です。

**シミュレーション**:
- 40歳から月2万円を年利5%で25年積み立て
- **65歳時点で約1,180万円**（元本600万円、運用益約580万円）

## 年代別：老後医療費・介護費準備の優先度

### 30〜40代
**優先度**: iDeCo・新NISAで長期積み立て開始

- iDeCo: 月1〜2万円（所得控除の節税効果が最大）
- 新NISA: 月2〜3万円（インデックスファンド）
- 医療保険: 掛け捨て型で月3,000〜5,000円

### 50代
**優先度**: 資産形成の加速 + 保険の見直し

- iDeCo: 上限まで拠出（節税を最大化）
- 保険: 死亡保障を減らし、医療保障を充実
- 親の介護計画の準備（兄弟と話し合い）

### 60代
**優先度**: 資産の取り崩し計画 + 高額療養費の知識習得

- iDeCo: 受け取り方（一時金 vs 年金）を試算
- 高額療養費制度・高額介護サービス費制度を把握
- 老人ホームの相場調査・事前登録

## まとめ：老後の医療費・介護費は「知っておくだけ」でかなり違う

老後の医療費・介護費が怖い最大の理由は「無限に増えるのでは」という不安感です。

しかし実際には：
- **高額療養費制度**で医療費は月8〜9万円が上限
- **高額介護サービス費**で介護費も月4.4万円が上限
- **iDeCo・新NISA**で節税しながら老後資金を積み立てられる

「知識」と「早めの準備」で、老後の不安の大半は解消できます。まず今の保険を見直すか、iDeCo・NISAを始めることから一歩を踏み出しましょう。
