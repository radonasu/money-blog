「副業で20万円超えたら確定申告が必要らしいけど、具体的に何をすればいい？」「会社に副業がバレずに申告する方法は？」と悩んでいませんか？

この記事では、2026年最新版の副業確定申告のやり方を、**20万円の壁の真実・住民税申告・会社にバレない普通徴収・e-Tax手順・節税テクニック**まで初心者にも分かるように完全解説します。

## 副業確定申告 — 2026年の基本ルール

### 確定申告が必要なケース・不要なケース

| ケース | 確定申告 | 住民税申告 |
|--------|----------|-----------|
| 副業所得**20万円超** | **必要** | 不要（確定申告で完結） |
| 副業所得20万円以下 | 不要 | **必要** |
| 副業赤字 | 不要 | 不要（または還付申告） |
| 給与所得が2か所 | **必要** | 不要 |

### よくある誤解：「20万円の壁」の真実

- **「副業20万円以下なら何もしなくていい」は間違い**
- 所得税の確定申告は不要だが、**住民税申告は必要**
- 住民税申告を怠ると後日延滞税・追徴課税のリスク
- 副業1万円でも住民税の対象（金額に下限なし）

## 副業の所得区分と必要経費

### 副業の主な所得区分

| 副業の種類 | 所得区分 | 注意点 |
|-----------|---------|--------|
| アルバイト・パート | **給与所得** | 源泉徴収あり |
| ライター・YouTube | **雑所得**（事業所得も可） | 経費計上で節税 |
| メルカリ・転売 | 雑所得 or 事業所得 | 規模次第で事業 |
| 不動産賃貸 | **不動産所得** | 損益通算可 |
| 株・FX | **譲渡・雑所得** | 申告分離課税 |

### 雑所得 vs 事業所得の違い（2026年改正後）

| 項目 | 雑所得 | 事業所得 |
|------|--------|---------|
| 青色申告特別控除 | ❌ なし | ⭕ **最大65万円** |
| 損益通算 | ❌ 不可 | ⭕ 給与と通算可 |
| 損失繰越 | ❌ 不可 | ⭕ **3年間繰越** |
| 税務署判断目安 | 売上300万円未満 | 売上300万円超＋帳簿 |

**ポイント**: 副業の売上が継続的で年300万円超を目指すなら、**開業届を提出して事業所得**にすると節税効果が大きくなります。

### 認められる必要経費の例

| 経費項目 | 計上の目安 |
|---------|-----------|
| 自宅家賃 | **業務使用面積÷総面積**の按分 |
| 通信費（ネット・スマホ） | 業務使用比率（30〜50%が目安） |
| 書籍・セミナー代 | 業務関連なら全額 |
| パソコン・備品 | 10万円未満は全額・以上は減価償却 |
| 取材交通費 | 全額（記録必須） |

## 会社にバレない確定申告のやり方

### バレる仕組みは「住民税の通知」

会社員の住民税は給与天引き（特別徴収）が原則。副業所得が増えると、住民税が増額され**会社の経理にバレる**のが典型パターンです。

### 対策：住民税を「普通徴収」に変更する

確定申告書の**第二表**にある「住民税に関する事項」で:

```
給与・公的年金等以外の所得に係る住民税の徴収方法
☐ 給与から差引き（特別徴収）
☑ 自分で納付（普通徴収）
```

の**「自分で納付」にチェック**を入れます。

### 注意点：完璧な対策ではない

- 自治体によっては普通徴収を認めない場合あり
- アルバイト（給与所得）の副業は普通徴収にできない
- 結局、副業禁止規定に違反するリスクは残る

**最終的には「就業規則を確認」「副業可の会社を選ぶ」のが本筋です。**

## e-Taxでの確定申告 7ステップ（2026年版）

### 必要な準備物

| 項目 | 用途 |
|------|------|
| マイナンバーカード | 本人確認・電子申告 |
| スマートフォン | マイナポータル連携 |
| 源泉徴収票 | 本業の給与情報 |
| 副業の収支記録 | 売上・経費の集計 |
| 領収書・レシート | 経費の証拠 |

### 申告手順 7ステップ

1. **国税庁HPの「確定申告書等作成コーナー」**にアクセス
2. **マイナポータル連携**でログイン（マイナンバーカード必須）
3. **収入金額**を入力（給与・副業の雑所得 or 事業所得）
4. **必要経費**を入力（領収書ベースで集計）
5. **各種控除**を入力（医療費・寄付金・小規模企業共済等）
6. **住民税の徴収方法**で「自分で納付」を選択
7. **電子申告（e-Tax送信）**で完了

### 申告期限

- **申告期限**: 2027年2月16日〜3月15日（2026年分）
- 還付申告（払い過ぎ）は1月から可能・5年間遡及可

## 副業の確定申告で使える節税テクニック5選

### 1. 青色申告特別控除（最大65万円）

事業所得にして青色申告承認を受け、e-Tax＋電子帳簿保存で**控除額65万円**。所得税率20%なら**13万円の節税**。

### 2. 小規模企業共済（年84万円まで全額控除）

個人事業主・フリーランス向け退職金制度。掛金が**全額所得控除**。

### 3. iDeCo（年14.4〜81.6万円控除）

会社員の副業でも加入可能。掛金が**全額所得控除**＋運用益非課税。

### 4. ふるさと納税

副業で所得が増えた分、ふるさと納税の上限額もアップ。実質**2,000円の負担で返礼品**。

### 5. 経費の徹底計上

業務関連の支出を漏らさず計上:
- ネット代（業務使用比率分）
- スマホ代（業務使用比率分）
- 書籍代・セミナー代
- 取材費・打ち合わせのカフェ代

## 副業確定申告でよくある失敗5選

### 失敗1: 「20万円以下だから何もしない」

→ **住民税申告**は必要！

### 失敗2: 「現金収入だからバレない」

→ 銀行送金記録・取引先の支払調書で**ほぼバレる**

### 失敗3: 「経費は適当でいい」

→ 領収書・帳簿不備で**追徴課税のリスク**

### 失敗4: 「会社にバレるのが怖くて未申告」

→ **延滞税15%・無申告加算税15〜20%**で大ダメージ

### 失敗5: 「青色申告は難しそうだから白色申告で」

→ 65万円控除を逃すと**年13万円以上の損**（所得税率20%の場合）

## まとめ：副業を始めたら最初にやるべき3つ

副業を始めたら、**最初の1ヶ月以内**に:

1. **開業届を提出**（事業所得にできるかの判断）
2. **会計ソフトを導入**（freee・マネーフォワード・弥生）
3. **証拠書類の保管習慣**（レシート・領収書・契約書）

会計ソフトは**月1,000〜2,000円**で帳簿作成・確定申告書作成まで自動化できます。手書き・Excelで時間を浪費するより、ソフト導入で**時間と精神を節約**するのが正解です。
