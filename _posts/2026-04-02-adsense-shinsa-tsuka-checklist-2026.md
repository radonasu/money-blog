## AdSense審査は「準備した人だけが通過できる」

Google AdSenseの審査通過率は、申請サイトの品質によって大きく異なります。準備なしで申請すると**却下→再申請→却下**のループに陥ることも。

この記事では、2026年現在のAdSense審査基準をもとに、**一発合格を目指すための完全チェックリスト**を公開します。

---

## AdSense審査の基本情報（2026年版）

| 項目 | 内容 |
|------|------|
| 審査期間 | 通常1〜14日（長い場合は1ヶ月以上）|
| 審査方法 | Googleの自動審査+手動確認 |
| 必要コンテンツ数 | 明示されていないが「20記事以上・各1,000字以上」が目安 |
| 合格率 | 非公開（事前準備で大幅に改善可能） |

## 【必須チェックリスト①】コンテンツの品質

### ✅ 記事数と文字数
- [ ] 記事数が20本以上ある
- [ ] 各記事が1,000字以上（理想は1,500〜3,000字）
- [ ] 最新情報に更新されている（古い情報が多いと減点）

### ✅ オリジナリティ
- [ ] 他サイトのコピーではない独自コンテンツ
- [ ] 引用は適切な形式で（引用元を明記）
- [ ] AIで生成したコンテンツは**人間が追記・編集してオリジナル性を高める**
  - ※ AIコンテンツ自体は禁止ではないが、質と独自性が問われる

### ✅ 記事の品質
- [ ] 読者にとって有益な情報が含まれている
- [ ] 誤字脱字が少ない
- [ ] 見出し（H2/H3）が適切に使われている
- [ ] 画像や表など視覚的な要素がある（なくてもOKだが有利）

### ✅ NG コンテンツ（絶対に除外）
- [ ] 暴力・成人向けコンテンツがない
- [ ] 差別・ヘイトスピーチがない
- [ ] 薬物・武器に関する不適切なコンテンツがない
- [ ] 著作権侵害コンテンツがない

---

## 【必須チェックリスト②】必須ページの設置

### ✅ プライバシーポリシー（最重要）
- [ ] プライバシーポリシーページが存在する
- [ ] AdSenseを利用する旨の記載がある
- [ ] Cookieの使用について記載がある
- [ ] 個人情報の取り扱いについて記載がある
- [ ] ナビゲーションから到達できる位置にある（フッターなど）

### ✅ お問い合わせページ
- [ ] お問い合わせフォームまたはメールアドレスが設置されている
- [ ] ページがナビゲーションから到達できる

### ✅ 運営者情報（About）ページ
- [ ] サイト運営者のプロフィールが記載されている
- [ ] 匿名でも可だが、誰が運営しているか分かる情報があること
- [ ] サイトの目的・コンセプトが明記されている

### ✅ サイトマップ
- [ ] XMLサイトマップが生成されている（`/sitemap.xml`）
- [ ] Google Search Consoleにサイトマップを送信済み

---

## 【必須チェックリスト③】サイト設計・技術

### ✅ ドメインとURL
- [ ] サイトが公開されている（ローカルではなく本番URL）
- [ ] HTTPSで配信されている（SSL証明書あり）
- [ ] 独自ドメイン推奨（`github.io` や `blogspot.com` でも通過実績あり）

### ✅ ナビゲーション・UX
- [ ] ヘッダーまたはサイドバーにナビゲーションがある
- [ ] 各記事から必須ページ（プライバシーポリシー等）に辿り着ける
- [ ] モバイル表示が崩れていない（レスポンシブ対応）
- [ ] ページの読み込み速度が遅すぎない

### ✅ Google連携
- [ ] Google Search Consoleにサイトを登録済み
- [ ] サイトマップを送信済み（Googleのインデックスが加速する）
- [ ] Googleアナリティクス（GA4）を設置（任意だが有利）

## 【必須チェックリスト④】AdSense申請の手順

### ✅ 申請前の準備
- [ ] Googleアカウントを用意（AdSenseで使うアカウント）
- [ ] サイトのURLを確認（`https://`から始まる正確なURL）
- [ ] 住所・氏名・銀行口座情報を用意（審査通過後の報酬受け取りに必要）

### ✅ 申請手順
1. [Google AdSenseにアクセス](https://adsense.google.com/)
2. 「今すぐ申し込む」をクリック
3. サイトURLを入力
4. AdSenseコードを取得してサイトに貼り付け
5. 審査完了を待つ（通常1〜14日）

### ✅ AdSenseコードの設置
- [ ] `<head>` タグ内にAdSenseコードを貼り付けた
- [ ] コードが正しく設置されているか確認（ソースで確認）
- [ ] Jekyllの場合：`_includes/head.html` に追加

## よくある「審査却下」の原因と対策

### ❌ 原因1：コンテンツが不十分
**症状**: 記事数が少ない、文字数が少ない、内容が薄い

**対策**:
- 最低20記事以上に増やす
- 各記事を1,500字以上にリライト
- 実体験・具体的な数字を加えてオリジナリティを高める

### ❌ 原因2：プライバシーポリシーの不備
**症状**: ページがない、内容が不十分、リンクが切れている

**対策**:
- AdSense・Cookie・個人情報の3点を明記したポリシーを作成
- フッターからリンクできるようにする

### ❌ 原因3：サイトにアクセスできない
**症状**: ページが存在しない、HTTPSでない、ページエラーが発生

**対策**:
- 本番URLで全ページにアクセスできるか確認
- SSL証明書の有効期限を確認
- 404エラーになっているリンクをチェック

### ❌ 原因4：コピーコンテンツ
**症状**: 他サイトと同じ内容、AI生成そのままで独自性がない

**対策**:
- 各記事に自分の体験・意見・独自データを追加
- 引用する場合は適切な形式で
- 写真・グラフ・表など独自の視覚的要素を追加

## AdSense通過後にやること（収益最大化）

審査通過後は、以下の順で収益化を進めましょう：

### Step1: 広告ユニットの設置
- 記事上部（ファーストビュー直下）
- 記事内（H2見出しの直前）
- 記事下部（記事終わり）

**推奨**: 自動広告よりも手動で3箇所設置するほうがCTRが高い

### Step2: 高単価カテゴリに注力
AdSenseの単価が高いジャンル：
1. 金融（投資・保険・ローン）：クリック単価¥50〜500
2. 転職・就職：クリック単価¥30〜200
3. 法律・税務：クリック単価¥50〜300

金融ブログは**AdSenseと相性が非常に良い**カテゴリです。

### Step3: アフィリエイトとの組み合わせ
| PV数 | AdSense収益 | アフィリ収益 | 合計 |
|------|------------|------------|------|
| 月1,000PV | ¥300〜1,500 | ¥3,000〜15,000 | ¥5,000〜 |
| 月5,000PV | ¥1,500〜7,500 | ¥15,000〜75,000 | ¥20,000〜 |
| 月10,000PV | ¥3,000〜15,000 | ¥30,000〜150,000 | ¥50,000〜 |
| 月30,000PV | ¥9,000〜45,000 | ¥90,000〜450,000 | ¥150,000〜 |

金融系ブログはアフィリエイト単価が高いため、**AdSenseはあくまでサブ収益**と位置付け、アフィリエイト成約を最大化することが重要です。

## まとめ：チェックリストを使って万全の準備を

AdSense審査通過のポイントをまとめます：

1. **コンテンツ**: 20記事以上、各1,500字以上、独自性あり
2. **必須ページ**: プライバシーポリシー・お問い合わせ・About
3. **技術**: HTTPS・モバイル対応・Search Console登録済み
4. **申請手順**: AdSenseコードを正しく設置して申請

このチェックリストをすべて満たせば、審査通過率は大幅に上がります。

焦らず準備を整えてから申請することが、結果的に最短ルートです。
