# 不動産投資で節税する方法2026【サラリーマン向け・区分マンション投資の税効果完全解説】

不動産投資は「家賃収入で儲ける」だけでなく、**サラリーマンの給与所得と合算して税金を減らす「節税ツール」**としても注目されています。この記事では、不動産投資の節税の仕組みから、具体的なシミュレーション、注意点まで徹底解説します。

---

## なぜ不動産投資で節税できるのか？

不動産投資の節税の核心は**「損益通算」**と**「減価償却費」**の2つです。

### 仕組み①：損益通算（不動産所得 × 給与所得を相殺）

不動産所得が赤字になると、**給与所得と合算して課税所得を減らせます**。

```
例：年収600万円のサラリーマンが区分マンション1室を購入した場合
- 家賃収入：年72万円
- 経費（ローン利息・管理費・減価償却など）：年100万円
- 不動産所得：▲28万円（赤字）
↓ 損益通算
- 課税所得：600万円 - 28万円 = 572万円
- 節税効果：約8万〜11万円（所得税＋住民税）
```

### 仕組み②：減価償却費（建物の価値減少を経費にできる）

建物部分は毎年「減価償却費」として経費に計上できます。お金は出ていかないのに**帳簿上の赤字を作れる**のが節税のポイントです。

| 物件種別 | 耐用年数 | 減価償却率（定額法） |
|---------|---------|-----------------|
| 鉄筋コンクリート（RC）造 | 47年 | 2.1%/年 |
| 重量鉄骨造 | 34年 | 2.9%/年 |
| 木造 | 22年 | 4.5%/年 |
| 中古（築20年RC） | 10年 | 10%/年（**節税効果大**） |

**ポイント：中古物件は残存耐用年数が短く減価償却が早いため、節税効果が高くなります。**

## 年収別・節税効果シミュレーション

### ケース1：年収500万円・区分マンション1室（築25年RC・購入価格1,500万円）

| 項目 | 金額 |
|-----|------|
| 建物評価額 | 750万円（土地・建物50:50と仮定） |
| 減価償却費（残存耐用年数5年） | 150万円/年 |
| 家賃収入 | 72万円/年 |
| ローン利息・管理費等 | 60万円/年 |
| 不動産所得 | 72万 - 150万 - 60万 = **▲138万円** |
| 課税所得の減少 | 138万円減 |
| 節税額（所得税20%＋住民税10%） | **約41万円/年** |

> **5年間で最大205万円の節税効果**が期待できます（耐用年数が切れたら終了）。

### ケース2：年収800万円・区分マンション2室運用

年収800万円では所得税率が23%に上がるため、節税効果はさらに大きくなります。

- 不動産所得赤字：▲200万円/年
- 節税額：**約66万円/年**（所得税23%＋住民税10%）

## 節税に適した物件の選び方

### 選定基準3つ

**①築年数が古い中古物件**
耐用年数が短い物件ほど減価償却が大きく、節税効果が高い。
- 築20年以上のRC造：残存耐用年数10〜15年程度
- 築25年木造：耐用年数が切れており、法定耐用年数×20%で計算可能

**②建物比率が高い物件**
土地は減価償却できない。建物価値が高いほど経費計上できる金額が増える。
- 地方・郊外の物件：建物比率が高い傾向

**③ローンを活用する**
ローン利息は経費計上できる。フルローン（自己資金ゼロ）で購入すると利息が大きく、帳簿上の赤字が作りやすい。

## 確定申告での申告方法

不動産所得がある場合は**毎年2〜3月に確定申告**が必要です。

### 必要書類
- 賃貸借契約書
- 家賃収入の領収証・通帳
- ローン残高証明書（利息計算用）
- 固定資産税納税通知書
- 管理会社への支払い明細
- 減価償却費の計算書

### 主な経費として計上できるもの

| 経費項目 | 具体例 |
|---------|--------|
| ローン利息 | 元本は不可、利息のみ |
| 管理費・修繕積立金 | 毎月の支払い |
| 管理会社委託料 | 家賃の5〜10% |
| 固定資産税・都市計画税 | 年間納税額 |
| 損害保険料 | 火災保険・地震保険 |
| 減価償却費 | 建物価値の年間経費 |
| 交通費・通信費 | 物件管理に関するもの |

## 注意点：節税目的だけで始めるのは危険

### リスク①：出口戦略を考えないと損をする

減価償却が終わった後は節税効果がなくなります。また、不動産を売却する際に「売却益」が発生すると譲渡所得税がかかります。

- 所有期間5年以下：譲渡所得税**39.63%**（短期譲渡）
- 所有期間5年超：譲渡所得税**20.315%**（長期譲渡）

「節税で得した金額」＜「売却時の税金」になる可能性があるため、**出口まで含めたシミュレーションが不可欠**です。

### リスク②：空室リスク・家賃下落リスク

「節税のために買った物件」が空室になると、家賃収入がなく経費だけかかる状態になります。
- 立地・需要をしっかり調査する
- 空室率の低い都市部・駅近を選ぶ

### リスク③：「節税効果が大きい＝優良物件」ではない

節税効果が大きい古い物件は、修繕費・リフォーム費用がかかる可能性が高いです。節税額だけで判断せず、**キャッシュフロー（手取り収益）も重視**しましょう。
