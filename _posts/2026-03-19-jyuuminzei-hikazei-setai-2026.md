# 住民税非課税世帯 条件 2026【年収・家族構成別チェックリスト＆受けられる優遇一覧】

「住民税非課税世帯って、どんな人が対象？」

住民税が非課税になると、さまざまな給付金や福祉サービスの優遇を受けられます。しかし、判定基準が複雑で「自分が対象かどうか分からない」という声も多いです。

本記事では、住民税非課税世帯の条件・判定方法・受けられる優遇を2026年最新情報でわかりやすく解説します。

---

## 住民税非課税世帯とは？

住民税非課税世帯とは、**世帯全員が住民税（均等割）を課税されていない世帯**のことです。

住民税には「均等割」と「所得割」の2種類があります。よく「住民税非課税」と言う場合は、この両方が非課税（ゼロ）の状態を指すことが多いです。

---

## 住民税が非課税になる条件

### 条件①：所得が基準以下（最も一般的）

住民税の非課税基準は市区町村によって多少異なりますが、標準的な基準は以下の通りです。

| 世帯構成 | 非課税になる年収の目安 |
|----------|----------------------|
| 単身者（扶養なし） | 100万円以下（給与収入） |
| 夫婦2人（配偶者扶養） | 156万円以下 |
| 夫婦＋子1人 | 205万円以下 |
| 夫婦＋子2人 | 255万円以下 |
| 夫婦＋子3人 | 305万円以下 |

※「年収」は給与収入の場合。給与所得控除を差し引いた「所得」で判定するため、給与収入は上記より高くなります。

### 所得基準の計算式

**非課税所得基準 = 35万円 × （本人 + 扶養人数） + 10万円（2人以上の世帯は+21万円）**

例：夫婦2人（妻を扶養）の場合
- 35万円 × 2人 + 21万円 = **91万円以下**の所得が基準

給与所得の場合、年収から給与所得控除（最低55万円）を引いた額が「所得」になります。
- 年収156万円 → 所得 = 156万円 − 55万円 = **101万円**（やや超過）
- 年収155万円 → 所得 = 155万円 − 55万円 = **100万円**（100万円≒91万円に近い水準）

※実際の計算は自治体の「住民税非課税限度額」で確認してください。

### 条件②：生活保護を受けている

生活保護の受給者は、所得にかかわらず住民税が非課税になります。

### 条件③：障害者・未成年・寡婦・ひとり親

以下の条件を満たす方は、前年の合計所得が**125万円以下**の場合に非課税になります。
- 障害者（普通障害者・特別障害者）
- 未成年者（前年1月1日時点で18歳未満）
- 寡婦・ひとり親

## 住民税非課税世帯が受けられる優遇・給付金一覧

住民税非課税世帯になると、さまざまな優遇措置を受けられます。

### 1. 給付金・支援金

| 給付 | 内容 |
|------|------|
| 物価高騰対応給付金 | 1世帯あたり3万円〜7万円（時期・自治体による） |
| 子育て世帯向け給付金 | 子ども1人あたり別途給付（自治体によって異なる） |

### 2. 医療・介護

| 優遇 | 内容 |
|------|------|
| 国民健康保険料の軽減 | 均等割・平等割が7割・5割・2割軽減 |
| 高額療養費の区分 | 自己負担上限が低い区分（住院月8,000円上限等） |
| 後期高齢者医療保険料 | 軽減措置あり |
| 介護保険料 | 保険料段階が低くなる |

### 3. 教育

| 優遇 | 内容 |
|------|------|
| 高等学校等就学支援金 | 授業料の実質無償化 |
| 大学等授業料・入学金免除 | 国公立大学の授業料が無償〜減免 |
| 幼児教育・保育の無償化 | 0〜2歳の保育料が無償に |
| 奨学金 | 給付型奨学金の対象になりやすい |

### 4. 行政サービス

| 優遇 | 内容 |
|------|------|
| NHK受信料 | 全額免除（申請要） |
| 保育所保育料 | 無償または大幅軽減 |
| 公営住宅の優先入居 | 優先的に入居できる場合がある |

## 住民税非課税世帯の確認方法

### ①住民税決定通知書で確認する

毎年6月頃に届く「住民税決定通知書（特別徴収税額通知書）」を確認してください。
- 給与所得者：職場経由で受け取る
- 自営業者・無職の方：市区町村から直接郵送

通知書に「均等割・所得割ともに0円」と記載されていれば非課税です。

### ②市区町村の窓口・マイナポータルで確認

「住民税非課税証明書」を役所の窓口で取得できます（手数料約300円）。
マイナポータルからオンラインで確認・取得できる自治体も増えています。

以下の質問にすべて「はい」なら、非課税の可能性が高いです。

- [ ] 昨年の合計所得が「35万円×（本人+扶養人数）+加算額」以下だった
- [ ] または生活保護を受給している
- [ ] または障害者・未成年・寡婦・ひとり親で合計所得125万円以下
- [ ] 世帯全員が上記条件を満たしている

→ 3つ以上当てはまった方は、住民税非課税の可能性があります。市区町村の窓口や住民税通知書で確認しましょう。

## よくある質問（Q&A）

**Q：パートで働いていますが非課税世帯になれますか？**
A：年収と扶養状況次第です。配偶者の扶養に入っていれば、年収100万円以下なら単身でも非課税になります。年収103万円・130万円・150万円の各壁もあわせて確認しましょう。

**Q：住民税非課税世帯と住民税非課税は違いますか？**
A：「住民税非課税世帯」は世帯全員が非課税の場合。「住民税非課税（個人）」は本人のみが非課税の場合です。給付金などの対象は「世帯全員が非課税」が条件のことが多いため注意が必要です。

**Q：年度によって変わりますか？**
A：はい、住民税は前年の所得をもとに計算されます。育休・退職・収入減などで判定が変わることがあります。毎年6月の通知書で確認しましょう。

## まとめ：住民税非課税世帯のポイント

| ポイント | 内容 |
|----------|------|
| 対象 | 世帯全員の所得が基準以下 |
| 基準（目安） | 単身100万円・夫婦156万円・子1人205万円 |
| 確認方法 | 住民税通知書 or 市区町村窓口 |
| メリット | 給付金・保険料軽減・教育費無償化など多数 |

住民税非課税世帯は、適切に活用することで年間数十万円の節約につながる可能性があります。まずは自分の世帯が対象かどうか確認してみましょう。
