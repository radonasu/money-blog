# 節税対策まとめ2026【サラリーマン・フリーランス・法人別・最強節税術チェックリスト】

日本の税負担は年々増加しています。「税金は仕方ない」と諦めている人が多いですが、**正しい知識があれば合法的に税負担を大幅に減らせます。**

この記事では、働き方別（サラリーマン・フリーランス・法人）に節税対策を体系的にまとめます。年間数十万円の節税効果も狙えます。

## 第1章：サラリーマン（給与所得者）の節税術

### ① iDeCo（個人型確定拠出年金）
- **節税メリット**: 掛け金が全額所得控除 → 所得税・住民税が直接減る
- **年間最大掛け金**:
  - 会社員（企業年金なし）: **月23,000円 × 12 = ¥276,000**
  - 公務員: 月12,000円 × 12 = ¥144,000
- **節税額目安（年収500万円・月23,000円掛け）**: **年間約¥69,000節税**
- **注意**: 60歳まで引き出せない（老後資金として割り切る）

### ② ふるさと納税
- **仕組み**: 寄付した金額のうち2,000円を超える部分が翌年の住民税・所得税から控除
- **年収別おすすめ上限額**:
  - 年収400万円: 約¥42,000
  - 年収600万円: 約¥77,000
  - 年収800万円: 約¥129,000
- **実質2,000円で返礼品（食品・日用品）をもらえる**最強のコスパ節税

### ③ 医療費控除
- **対象**: 年間医療費が10万円超（または所得の5%超）
- **セルフメディケーション税制**: スイッチOTC医薬品購入額12,000円超で適用可
- **意外と見落とされる対象**: 歯科矯正・不妊治療・通院交通費・市販薬（一部）

### ④ 生命保険料控除・地震保険料控除
- **生命保険料控除**: 一般生命・介護医療・個人年金の3種類、最大¥120,000控除
- **地震保険料控除**: 保険料の全額（上限¥50,000）が控除
- **合計最大節税額**: 年間約¥25,000〜30,000（所得税+住民税合算）

### ⑤ 住宅ローン控除（住宅借入金等特別控除）
- **2024年入居の控除額**: 借入残高 × 0.7%（上限¥140,000〜350,000/年）
- **控除期間**: 13年間（新築・リフォーム要件あり）
- **累計節税効果**: 最大¥2,000,000〜4,550,000

### ✅ サラリーマン節税チェックリスト
- [ ] iDeCo口座を開設して毎月積立設定している
- [ ] ふるさと納税を上限額まで活用している
- [ ] 年間医療費が10万円を超えていないか確認した
- [ ] 生命保険・地震保険の控除証明書を年末調整で提出している
- [ ] 住宅ローン残高証明書を忘れずに提出している

## 第2章：フリーランス・個人事業主の節税術

フリーランスは「サラリーマン+追加の節税策」が使えるため、節税の幅が大きく広がります。

### ① 青色申告特別控除（最大65万円）
- **条件**: 複式簿記 + e-Tax申告 + 期限内申告
- **節税額目安（年収600万円）**: **年間約¥200,000節税**
- **会計ソフトでほぼ自動化可能**（freee・マネーフォワード等）

### ② 小規模企業共済
- **掛け金**: 月1,000〜70,000円（全額所得控除）
- **年間最大掛け金**: ¥840,000
- **節税額目安（課税所得500万円・最大掛け）**: **年間約¥252,000節税**
- **廃業時・退職時に退職金として受け取れる**（さらに退職所得控除で節税）

### ③ 経費の最大化（見落としがちな項目）
| 経費項目 | 詳細 |
|---------|-----|
| 自宅オフィス（家賃） | 仕事に使う面積の割合を按分 |
| スマホ・インターネット | 仕事利用分（50〜80%）を按分 |
| 書籍・セミナー | 業務関連のものは全額経費 |
| 交通費 | 交通系ICカードの明細を保存 |
| 健康診断費用 | 事業に関連する場合は経費 |
| 生命保険 | 節税型の保険（注意点あり） |

### ④ 青色専従者給与（配偶者・家族に給与支払い）
- **条件**: 配偶者・家族が実際に業務に従事している
- **節税効果**: 給与額を経費に計上 + 配偶者が給与所得控除(¥550,000)を活用
- **例**: 配偶者に月10万円支払う → 年間¥120,000が丸ごと経費

### ⑤ iDeCo（フリーランスは最大月68,000円）
- **サラリーマンの3倍の拠出限度額**
- **年間最大¥816,000の所得控除**（節税額約¥200,000〜300,000）

### ✅ フリーランス節税チェックリスト
- [ ] 青色申告の申請をしている（白色申告のままになっていないか）
- [ ] 会計ソフト（freee / マネーフォワード）で帳簿をつけている
- [ ] 小規模企業共済に加入して最大掛け金を設定している
- [ ] 自宅家賃・スマホ料金を按分して経費計上している
- [ ] iDeCoで月68,000円（上限）を積み立てている

## 第3章：法人（中小企業・一人会社）の節税術

### ① 役員報酬の最適化
- **法人税率**: 中小企業は実効税率約25〜35%
- **個人所得税率**: 課税所得1,800万円超は45%
- **最適戦略**: 法人利益と個人所得税率が均等になる役員報酬を設定
- **目安**: 法人利益が年間800万円以下なら「法人に利益を残す」が有利なケースも

### ② 退職金の活用（節税効果が最大の手法）
- **仕組み**: 退職金は退職所得として分離課税 → 「退職所得控除+1/2課税」で節税効果絶大
- **例**: 30年勤務の退職金1,500万円 → 退職所得控除1,500万円 → **税金¥0**
- **小規模企業共済と組み合わせると効果倍増**

### ③ 経費の法人化（個人ではできない項目）
- 社宅（家賃の50〜75%が経費）
- 出張日当（非課税・法人側も経費）
- 福利厚生費（社員旅行・慶弔費等）
- 倒産防止共済（月20万円まで、40ヶ月で800万円全額経費）

### ④ 決算前節税対策3選
1. **倒産防止共済の加入・前払い**（最大800万円を一括経費化）
2. **在庫・設備投資の前倒し計上**（減価償却の活用）
3. **30万円未満の少額減価償却資産の即時償却**（中小企業特例）

### ✅ 法人節税チェックリスト
- [ ] 役員報酬を法人税率と個人所得税率を比較して最適化している
- [ ] 退職金積立のために小規模企業共済・倒産防止共済に加入している
- [ ] 社宅契約で役員の住居費を法人経費化している
- [ ] 決算前に合法的な経費前払い処理を実施している

## 全体まとめ：今すぐできる節税ランキング

### 🏆 即日実行可能な節税TOP3

**第1位: ふるさと納税（今すぐ申し込める）**
- 手続き5分・返礼品でお得・確定申告or ワンストップ特例で控除

**第2位: iDeCo口座開設（申込から1〜2ヶ月）**
- 手続き30分・毎月自動で節税・老後資産も同時に形成

**第3位: 確定申告での医療費控除（毎年2〜3月）**
- 領収書をまとめておくだけ・10万円超なら申請必須

### 💡 节税の優先順位

1. **iDeCo × 新NISA** → 所得控除 + 運用益非課税の最強コンボ
2. **ふるさと納税** → 実質2,000円で日用品・食品をゲット
3. **青色申告（フリーランス）** → 65万円控除・小規模企業共済との組み合わせ
4. **医療費控除** → 家族合算で申請・5年以内遡及も可能
5. **住宅ローン控除** → 最大13年間・最大¥455万円の節税

## まとめ

節税は「やり方を知っているか知らないか」の差です。同じ収入でも、節税の知識があるだけで**年間数十万円の手取りの差**が生まれます。

まずはiDeCoとふるさと納税から始め、確定申告を通じて医療費控除・各種所得控除を最大化しましょう。フリーランスや法人の方は青色申告・小規模企業共済・退職金設計を組み合わせることで、さらに大きな節税効果が得られます。
