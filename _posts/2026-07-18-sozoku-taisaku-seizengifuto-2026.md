# 相続対策・生前贈与2026【非課税枠を最大活用して相続税を減らす完全ガイド】

「自分が亡くなった後、子どもたちに多く遺してあげたい」——こう思っている親御さんは多いでしょう。

しかし、何も対策しなければ相続財産に対して**最高55%の相続税**が課される可能性があります。一方、生前から計画的に贈与を行えば、合法的に相続税の負担を大幅に軽減できます。

本記事では、**2024〜2026年の制度改正を踏まえた最新の生前贈与戦略**を解説します。

---

## 相続税の基礎：いくらから課税される？

### 基礎控除額の計算式

```
基礎控除額 = 3,000万円 + 600万円 × 法定相続人の数
```

**例：法定相続人が妻+子2人の場合**
- 基礎控除 = 3,000万円 + 600万円 × 3人 = **4,800万円**
- 財産が4,800万円以下なら相続税は**ゼロ**

| 相続人数 | 基礎控除額 |
|---------|----------|
| 1人 | 3,600万円 |
| 2人 | 4,200万円 |
| 3人 | 4,800万円 |
| 4人 | 5,400万円 |

### 相続税率（2026年時点）

| 課税遺産総額 | 税率 | 控除額 |
|------------|-----|-------|
| 1,000万円以下 | 10% | — |
| 3,000万円以下 | 15% | 50万円 |
| 5,000万円以下 | 20% | 200万円 |
| 1億円以下 | 30% | 700万円 |
| 2億円以下 | 40% | 1,700万円 |
| 3億円以下 | 45% | 2,700万円 |
| 6億円以下 | 50% | 4,200万円 |
| 6億円超 | 55% | 7,200万円 |

## 生前贈与の主要4パターン

### パターン①：暦年贈与（110万円の非課税枠）

**仕組み：**
年間110万円までの贈与は贈与税がかかりません。

**改正後の注意点（2024年1月〜）：**
2024年から**相続開始前7年以内**の贈与は相続財産に持ち戻される（改正前は3年）。ただし、4〜7年前の贈与は合計100万円まで控除あり。

**節税シミュレーション（親→子2人に10年間贈与の場合）:**

| 贈与額/年 | 10年間の贈与総額 | 相続財産からの減少額 | 相続税節税額（目安） |
|----------|----------------|-------------------|------------------|
| 110万円×2人 | 2,200万円 | 相続前3年分除き1,540万円 | 約230万〜460万円 |
| 200万円×2人 | 4,000万円 | 相続前3年分除き2,800万円 | 約420万〜840万円 |

**暦年贈与の実施方法（証拠を残す3点セット）：**
1. 贈与契約書を毎年作成（書式は何でもOK）
2. 振込で贈与する（現金手渡しは証拠が残らない）
3. 受け取った側が自由に使える（親が管理しない）

### パターン②：相続時精算課税制度

**2024年改正で大幅に使いやすくなりました！**

| 項目 | 2024年改正前 | 2024年〜現在 |
|------|------------|------------|
| 基本控除 | 累計2,500万円 | 累計2,500万円（変わらず） |
| 年間基礎控除 | なし | **新設：年110万円** |
| 選択後の変更 | 不可 | 不可 |

**2024年以降のポイント：**
- 年110万円の基礎控除が新設 → 毎年110万円以下の贈与は相続財産への持ち戻しなし
- 60歳以上の親→18歳以上の子・孫への贈与で利用可能
- 累計2,500万円超の贈与には一律20%の贈与税（相続時に精算）

**こんな人に向いている：**
- 不動産など値上がりが期待される資産を早期に移転したい
- 事業承継で自社株を早期に後継者に渡したい

### パターン③：教育資金の一括贈与（非課税）

**概要：**
祖父母→孫（30歳未満）への教育資金として最大**1,500万円**まで非課税で贈与可能。

| 条件 | 内容 |
|------|------|
| 対象者 | 30歳未満の子・孫 |
| 上限額 | 1,500万円（習い事等は500万円まで） |
| 手続き | 金融機関で「教育資金口座」を開設 |
| 期限 | 2026年3月31日まで（※制度延長の可能性あり） |
| 注意点 | 贈与者が死亡した場合、残額は相続財産に加算される場合あり |

### パターン④：住宅取得資金の贈与（非課税）

**概要：**
父母・祖父母→子・孫への住宅取得資金として最大**1,000万円**（省エネ住宅は1,500万円）まで非課税。

| 条件 | 内容 |
|------|------|
| 対象 | 18歳以上の子・孫（所得2,000万円以下） |
| 上限額 | 一般住宅¥1,000万円、省エネ住宅¥1,500万円 |
| 期限 | 2026年12月31日まで |

## 相続対策のロードマップ：今すぐできること

### 【財産1億円未満の場合】
相続税の課税対象外か、かかっても小額。優先度は低いが、以下を検討：
- 生命保険の活用（500万円×法定相続人数が非課税枠）
- 暦年贈与の開始（早ければ早いほど効果大）

### 【財産1〜3億円の場合】
積極的な節税対策が必要。
- 暦年贈与（毎年110万円×子供数）を即開始
- 教育資金・住宅資金贈与の活用
- 生命保険の非課税枠活用
- 不動産の活用（時価より相続税評価額が低くなることが多い）

### 【財産3億円超の場合】
専門家（税理士）との連携が必須。
- 相続税精算課税の活用
- 法人設立による資産移転
- 養子縁組による基礎控除増加
- 不動産小口化商品の活用

## 相続対策の注意点：避けるべき3つの落とし穴

### 落とし穴①：名義預金（税務調査で発覚しやすい）
子供名義の口座でも、実質的に親が管理している場合は「名義預金」として親の相続財産に含まれます。

**回避策：** 子供が自分で通帳・印鑑を管理し、実際に自由に使える状態にする

### 落とし穴②：毎年同額贈与による「定期贈与」認定
毎年ぴったり110万円を贈与し続けると「最初から総額を贈与する約束があった」と判断され、一括で贈与税が課される場合があります。

**回避策：** 金額を年ごとに変える（例：100万円→120万円→90万円）、日付も毎年変える

### 落とし穴③：制度改正への対応不足
2024年の暦年贈与の持ち戻し期間延長（3年→7年）など、制度は変わり続けます。

**回避策：** 定期的に税理士に相談する

## プロ（税理士）に相談すべきタイミング

- 財産総額が基礎控除を超えそうな場合
- 不動産・自社株など評価が難しい資産がある場合
- 親が高齢で早急な対策が必要な場合
- 相続人の間で揉め事が起きそうな場合

> 💡 **無料相談から始めよう**：税理士ドットコム・相続税の申告を専門とする税理士事務所では、初回相談無料の事務所も多くあります。まず気軽に相談してみましょう。相続税は「知らなかった」では済まされないため、早めの対策が肝心です。

---

## まとめ：生前贈与で相続税を賢く減らす5ステップ

1. **まず財産総額を把握**する（不動産・預金・株式等を全て書き出す）
2. **基礎控除と照らし合わせ**て課税対象になるか確認する
3. **暦年贈与を今すぐ開始**する（毎年110万円×子供数、証拠を残して）
4. **特例制度を活用**する（教育資金・住宅資金贈与）
5. **定期的に税理士に相談**して最新の制度変更に対応する

**「知っているだけで数百万円の差が出る」**のが相続対策です。早めに動き出した人ほど有利になります。
