「病院代や薬代が多くかかった年、何か取り戻せないのか？」

答えはYESです。**医療費控除**を使えば、1年間の医療費が10万円を超えた分を所得から差し引き、払いすぎた税金を取り戻せます。会社員でも確定申告で申請可能です。

この記事では2026年最新の医療費控除の仕組み・計算方法・申告手順を実例付きで解説します。

---

## 医療費控除とは？基本の仕組み

医療費控除とは、1年間（1月1日〜12月31日）に支払った医療費が**10万円（または所得の5%）を超えた場合**、その超過分を所得から差し引ける制度です。

**控除できる金額の上限：200万円**

### 計算式

```
医療費控除額 = 実際に支払った医療費 − 10万円（または所得の5%）
還付される税金 = 医療費控除額 × 所得税率
```

> 所得税率は所得に応じて5〜45%。年収400〜600万円のサラリーマンは概ね20%。

## 実際いくら戻ってくる？シミュレーション3例

### ケース①：年収500万円の会社員、医療費15万円

| 項目 | 金額 |
|------|------|
| 実際の医療費 | 150,000円 |
| 差し引く額（10万円） | −100,000円 |
| 医療費控除額 | 50,000円 |
| 所得税還付（税率20%） | **10,000円** |
| 住民税軽減（税率10%） | **5,000円** |
| **合計還付・軽減額** | **約15,000円** |

### ケース②：年収400万円、家族4人分の医療費25万円

| 項目 | 金額 |
|------|------|
| 実際の医療費 | 250,000円 |
| 差し引く額 | −100,000円 |
| 医療費控除額 | 150,000円 |
| 所得税還付（税率20%） | **30,000円** |
| 住民税軽減 | **15,000円** |
| **合計還付・軽減額** | **約45,000円** |

### ケース③：年収300万円（所得の5%ルール適用）、医療費13万円

所得が200万円未満の場合は「所得の5%」が基準に。
年収300万円→給与所得控除後の所得は約200万円→基準額は10万円（5%=10万円で10万円が適用）

| 項目 | 金額 |
|------|------|
| 実際の医療費 | 130,000円 |
| 差し引く額 | −100,000円 |
| 医療費控除額 | 30,000円 |
| **合計還付・軽減額** | **約9,000円** |

## 医療費控除の対象になるもの・ならないもの

### ✅ 対象になる主なもの

| 種類 | 具体例 |
|------|--------|
| 病院・診療所 | 診察料、手術費、入院費 |
| 歯科治療 | 虫歯治療、インプラント（※美容目的はNG） |
| 処方薬 | 処方箋による薬代 |
| 市販薬 | 風邪薬・胃腸薬など（※通常は対象外、セルフメディケーションは別途） |
| 通院交通費 | 電車・バス代（自家用車ガソリン代はNG） |
| 出産費用 | 入院・分娩費用（出産育児一時金を差し引いた額） |
| 介護サービス | 介護保険の自己負担分 |
| 妊婦検診 | 定期健診費用 |

### ❌ 対象にならないもの

- 美容整形・美容歯科（ホワイトニングなど）
- 健康診断・人間ドック（疾病が見つかり治療につながった場合は対象）
- 予防接種・インフルエンザワクチン
- 医療保険の保険料
- 眼鏡・コンタクト（治療目的でない）

## セルフメディケーション税制との比較

**セルフメディケーション税制**は、市販薬（スイッチOTC医薬品）を年間1万2,000円超購入した場合に適用できる別の制度。

| 比較項目 | 医療費控除 | セルフメディケーション税制 |
|---------|-----------|------------------------|
| 適用条件 | 年間医療費10万円超 | 特定市販薬1.2万円超 |
| 控除上限 | 200万円 | 8.8万円（最大） |
| 病院受診 | 不要 | 定期健診等が必要 |
| 同時利用 | — | どちらか一方のみ |

> 病院にあまり行かず市販薬で済む方はセルフメディケーション税制が有利な場合も。

## 申告に必要なもの

1. **医療費の領収書** — 病院・薬局発行（5年保存）
   - 2020年分以降：マイナポータルから医療費通知情報を取得可能（自動入力）
2. **源泉徴収票** — 勤務先から発行
3. **マイナンバーカードまたは通知カード**
4. **振込先口座情報**（還付金受取用）

---

## 申告方法：e-Taxが最もカンタン

### ステップ1：医療費を集計する

**マイナポータル連携で自動入力（おすすめ）**
- マイナンバーカード取得済みの場合、国税庁の確定申告書等作成コーナーからマイナポータルと連携すると、健康保険組合の医療費データが自動入力される
- 差額分（保険適用外・市販薬など）を手入力で追加

**手動集計の場合**
- 医療費控除の明細書（国税庁サイトから無料ダウンロード）に記入

### ステップ2：確定申告書を作成

国税庁「[確定申告書等作成コーナー](https://www.keisan.nta.go.jp/)」にアクセス
1. 「所得税の確定申告書」を選択
2. 給与所得を入力（源泉徴収票の数字をそのまま転記）
3. 「医療費控除」を選択し、金額を入力
4. 還付金額が自動計算される

### ステップ3：提出

- **e-Tax（マイナンバーカード＋スマホ）**：その場で完結、最も簡単
- **郵送**：印刷して税務署に送付
- **持参**：税務署窓口

### 申告期間

| 年分 | 申告期間 |
|------|---------|
| 2025年分 | 2026年2月16日〜3月15日（還付申告は1月1日から可） |
| ※還付のみの場合 | 5年間さかのぼって申告可能 |

> 医療費控除は「還付申告」のため、税務署の混む時期を外して1〜2月や3月下旬に申告するとスムーズ。

---

## 5年さかのぼり申告で最大〇万円の還付も

医療費控除の還付申告は**過去5年分**さかのぼれます。

「昨年や一昨年に医療費が多かったが申告しなかった」という方は今からでも申告可能です。

| さかのぼれる年分（2026年時点） |
|-------------------------------|
| 2021年分〜2025年分（合計5年分） |

## 医療費控除でよくある疑問Q&A

**Q. 家族全員分の医療費をまとめて申告できる？**
A. できます。生計を一にする家族（配偶者・子・親など）の医療費はまとめて申告可能。一番所得の高い人が申告すると還付額が大きくなります。

**Q. 医療費の領収書は提出が必要？**
A. e-Taxの場合は提出不要（5年間の自宅保管が必要）。書面申告の場合も2020年分以降は提出不要で、明細書の添付が原則です。

**Q. 歯のインプラントは対象？**
A. 治療目的（虫歯・噛み合わせ改善等）は対象。美容目的は対象外。

**Q. 出産費用はどうなる？**
A. 出産育児一時金（42万円）を差し引いた実費が対象。自然分娩で高額になりやすく、申告すると数万円戻ることも。

---

## まとめ：医療費控除は「ほぼリスクゼロ」の節税

| ポイント | 内容 |
|---------|------|
| 対象者 | 年間医療費10万円超の人すべて |
| 手間 | e-Taxなら30〜60分で完結 |
| リターン | 最低でも数千円〜数万円の還付 |
| リスク | ほぼゼロ（正確な申告なら問題なし） |

医療費控除は「申告しないと損をする制度」の代表格です。領収書を大切に保管し、年度末にまとめて申告しましょう。
