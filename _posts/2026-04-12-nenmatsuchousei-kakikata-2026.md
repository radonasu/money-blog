# 年末調整 書き方 2026【各書類の記入例と節税チェックリスト完全ガイド】

毎年10〜11月になると会社から渡される「年末調整書類」。記入が面倒で、何となく書いて提出していませんか？実は**年末調整は会社員最大の節税機会**です。正しく記入するだけで数万〜数十万円の税金が戻ってくる可能性があります。

この記事では、2026年版の年末調整書類の書き方を、記入例と節税チェックリスト付きで徹底解説します。

---

## 年末調整とは？確定申告との違い

**年末調整**とは、会社が従業員の代わりに行う所得税の精算手続きです。

- 毎月の給与から天引きされている源泉徴収税は「概算額」
- 年末に実際の年収・各種控除を計算して、払いすぎた税金を還付（または追加徴収）する
- **会社員の約99%は年末調整だけで納税が完結**（確定申告不要）

| 項目 | 年末調整 | 確定申告 |
|------|---------|---------|
| 手続き者 | 会社（代行） | 本人 |
| 時期 | 10〜11月書類提出、12月精算 | 翌年2〜3月 |
| 対象 | 給与所得者 | 個人事業主・確定申告が必要な人 |
| 申告方法 | 紙書類を会社に提出 | e-Tax or 税務署 |

## 2026年の年末調整 主要書類一覧

### 書類①：給与所得者の扶養控除等（異動）申告書

**全員が提出必須**の基本書類です。

**記入のポイント**：
- **自分の情報**（住所・マイナンバー等）を正確に
- **配偶者・扶養家族の情報**を漏れなく記入
- 16歳未満の子供は「住民税の扶養控除」のみ対象（所得税の扶養控除対象は16歳以上）

**扶養控除の額（1人あたり）**：

| 扶養親族の区分 | 控除額 |
|---|---|
| 16歳以上19歳未満 / 23歳以上70歳未満 | 38万円 |
| **特定扶養親族（19〜23歳）** | **63万円**（大学生・専門学生は必ずチェック） |
| 老人扶養親族（70歳以上・同居） | 58万円 |
| 老人扶養親族（70歳以上・別居） | 48万円 |

> ⚠️ **申告漏れ多発ポイント**：大学生の子供（19〜22歳）がいる場合、「特定扶養親族」に記入すると**63万円の控除**。年収600万円の場合、所得税＋住民税で約10万円の節税になります。

---

### 書類②：給与所得者の保険料控除申告書

**生命保険・地震保険・社会保険**等の控除を申告する書類。

#### 生命保険料控除

| 保険の種類 | 最高控除額（所得税） |
|---|---|
| 一般生命保険料（死亡保険等） | 4万円 |
| 介護医療保険料 | 4万円 |
| 個人年金保険料 | 4万円 |
| **合計最高控除額** | **12万円** |

**記入例**：
```
一般生命保険料：
  保険会社名：○○生命保険
  保険の種類：終身保険（死亡保険）
  保険期間：終身
  受取人：配偶者
  支払保険料：120,000円
  → 控除証明書の記載額を転記する
```

#### 地震保険料控除

- 地震保険料：最高5万円（支払保険料の全額）
- 旧長期損害保険料：最高1.5万円

> 💡 **控除証明書の確認が重要**：10〜11月に保険会社から「控除証明書」が届きます。紛失した場合は再発行を依頼してください。

### 書類③：給与所得者の基礎控除申告書 兼 配偶者控除等申告書 兼 所得金額調整控除申告書

2020年から3つの書類が1枚に統合されました。

#### 基礎控除（全員が受けられる）

| 合計所得金額 | 控除額 |
|---|---|
| 2,400万円以下 | **48万円** |
| 2,400万円超2,450万円以下 | 32万円 |
| 2,450万円超2,500万円以下 | 16万円 |
| 2,500万円超 | 0円 |

#### 配偶者控除・配偶者特別控除

**配偶者控除**（配偶者の年収が103万円以下）：

| 本人の合計所得金額 | 控除額 |
|---|---|
| 900万円以下 | **38万円** |
| 900万円超950万円以下 | 26万円 |
| 950万円超1,000万円以下 | 13万円 |

**配偶者特別控除**（配偶者の年収が103万円超201.6万円以下）：
- 本人・配偶者の収入によって段階的に控除額が決まる
- 最大38万円の控除

> ⚠️ **103万円・130万円・150万円・201.6万円の壁**：配偶者のパート収入によって税・社会保険への影響が変わります。家庭の状況に合わせて計画を。

---

### 書類④：住宅借入金等特別控除申告書（住宅ローン控除）

住宅ローンを利用して住宅を購入・増改築した人が対象。初年度のみ確定申告、**2年目以降は年末調整で手続き完結**。

**必要書類**：
- 税務署から送られてくる「年末調整のための住宅借入金等特別控除証明書」
- 金融機関発行の「住宅取得資金に係る借入金の年末残高等証明書」

**控除額の計算**：
> 控除額 = 年末ローン残高 × 0.7%（2022年以降の新築・取得）

## 節税チェックリスト（申告漏れ防止）

```
□ 16〜22歳の子供がいる → 扶養控除（特定扶養は63万円）
□ 配偶者の年収が201.6万円未満 → 配偶者控除・特別控除
□ 生命保険に加入 → 生命保険料控除証明書を添付
□ 地震保険に加入 → 地震保険料控除証明書を添付
□ 住宅ローンがある（2年目以降） → 住宅借入金等特別控除
□ iDeCoに加入 → 小規模企業共済等掛金控除証明書を添付
□ 個人年金保険に加入 → 個人年金保険料控除証明書を添付
□ 障害者手帳を持つ家族がいる → 障害者控除（27万〜75万円）
□ ひとり親世帯 → ひとり親控除（35万円）
```

## 年末調整では申告できない控除（確定申告が必要）

以下の控除は年末調整では申告できません。翌年2〜3月の確定申告が必要です：

| 控除の種類 | 内容 |
|---|---|
| 医療費控除 | 年間医療費が10万円超の場合 |
| 寄附金控除 | ふるさと納税（ワンストップ特例を使わない場合） |
| 雑損控除 | 災害・盗難による損失 |
| 初年度の住宅ローン控除 | 1年目のみ確定申告 |
| 副業・兼業収入（20万円超） | 別途確定申告 |

---

## まとめ：年末調整で必ず確認すべき3点

1. **扶養家族の情報は毎年更新**：子供の年齢・就職状況、親の収入変化を確認
2. **控除証明書は10〜11月に届く**：保険会社・銀行からの書類を紛失しない
3. **申告漏れは5年以内なら遡及申請可能**：過去の漏れは「更正の請求」で取り戻せる

年末調整の書類提出は毎年1度のチャンス。正しく申告して、本来受け取れるべき税金の還付をしっかり受け取りましょう。
