## 「夫婦のお金」で揉めないための仕組みを作ろう

夫婦間のお金の問題は、離婚原因のトップ3に入るほど重要なテーマです。しかし、学校では「夫婦のお金の管理法」は教えてくれません。

この記事では、**共働きと片働きそれぞれのケースで最適な家計管理の仕組み**を、具体的な数字とともに解説します。

---

## 夫婦の財布管理「4つのパターン」

| タイプ | 特徴 | 向いている夫婦 |
|-------|------|--------------|
| **① 完全合算型** | 全収入を共通口座に集約 | 管理を一元化したい・信頼度が高い |
| **② 生活費折半型** | 生活費は折半・残りは各自管理 | 共働き・個人の自由を確保したい |
| **③ 費目分担型** | 家賃は夫、食費は妻など役割分担 | 明確な役割分担を好む夫婦 |
| **④ 生活費拠出型** | 各自が一定額を生活費口座に拠出 | 収入差がある共働き夫婦 |

### 最もトラブルが少ない「生活費拠出型」の仕組み

```
夫 (手取り40万) → 生活費口座に20万 → 残り20万は個人
妻 (手取り25万) → 生活費口座に12.5万 → 残り12.5万は個人
                    ↓
               生活費口座から
               家賃・食費・光熱費・保険を支払い
```

ポイント：**手取り収入の50%を生活費に拠出**（収入比率に応じて調整可）

## 共働き夫婦の最適家計設計

### 基本モデル（夫35万・妻25万の手取りの場合）

| 項目 | 月額 | 担当 |
|-----|------|------|
| 家賃・住宅ローン | 10万 | 夫 |
| 食費 | 4万 | 共通口座 |
| 光熱費・通信費 | 2万 | 共通口座 |
| 保険（生命・医療） | 2万 | 共通口座 |
| 子どもの教育費 | 2万 | 妻 |
| 夫婦の貯蓄・投資 | 10万 | 共通口座 |
| 夫個人の小遣い | 5万 | 夫個人 |
| 妻個人の小遣い | 5万 | 妻個人 |

→ **夫婦で月10万を投資に回せば、30年後に約8,000万円**（年率6%複利）

### 「妻名義」のNISA口座を活用する重要性

共働き夫婦でよくある失敗：夫だけ投資口座を持っている。

**夫婦それぞれのNISA口座を持つことで：**
- 年間投資上限: 360万円 × 2人 = **720万円**（夫婦合計）
- 生涯非課税枠: 1,800万円 × 2人 = **3,600万円**
- 相続時の節税効果も高まる

## 片働き夫婦の最適家計設計

### 基本モデル（夫手取り40万・妻専業主婦）

**「小遣い制は関係を悪化させる」罠に注意**

夫が全額管理・妻に小遣いを渡す方式は、妻の「お金の自立性」を奪い、長期的に関係を悪化させます。

**推奨モデル：生活費を夫が管理・残りを半分ずつ「お互いの自由枠」に**

| 項目 | 月額 | 備考 |
|-----|------|------|
| 固定費（家賃・保険・通信） | 12万 | 夫が管理 |
| 変動費（食費・日用品・外食） | 8万 | 妻が管理 |
| 貯蓄・投資（NISA・iDeCo） | 8万 | 共同で決定 |
| 夫の自由枠 | 6万 | 夫の判断で使用 |
| 妻の自由枠 | 6万 | 妻の判断で使用 |

→ 妻の「自由枠6万円」は家計からの「給与」と位置づけることで対等性が保たれる

## 夫婦の投資口座設計

### 共働き夫婦の黄金パターン

```
夫: 新NISA（つみたて120万+成長240万）→ iDeCo（月2.3万）
妻: 新NISA（つみたて120万+成長240万）→ iDeCo（月2.3万）

夫婦合算の月間積立上限：
NISA: 月30万（360万÷12か月）×2人 = 実質月60万まで非課税枠
iDeCo: 月4.6万（2.3万×2人）= 年55.2万の所得控除
```

### 片働き夫婦の場合

- 夫のiDeCo: 月2.3万（所得税・住民税の節税効果最大）
- 妻のiDeCo: 専業主婦は月6.8万まで（所得がないため節税効果なし・資産形成のみ）
- 妻のNISA: 夫の収入から生活費口座を通じて積立可能

## 「夫婦のお金」でよくある失敗5選

### 失敗①：話し合いが一度もない
毎月15日を「家計会議の日」に設定。30分だけでOK。

### 失敗②：どちらかだけが把握している
マネーフォワードMEで家族共有設定 → お互いが口座残高・支出をリアルタイムで把握

### 失敗③：投資口座がない
2人ともNISA口座を持っていれば、老後2,000万円問題は自動的に解決する可能性が高い。

### 失敗④：保険に入りすぎている
生命保険は「残された家族が必要な額」を計算してから加入を検討。子どもがいない共働き夫婦に多額の死亡保険は不要なケースが多い。

### 失敗⑤：緊急予備費を別々に積んでいる
夫婦合計で「生活費6ヶ月分」あれば十分。2人分を別々に積むと機会損失（その分を投資に回せる）。

## まとめ：夫婦のお金管理「最初の3ステップ」

**今週中にできること:**
1. **お互いの収入・貯蓄・借金を開示**（信頼関係の基盤）
2. **マネーフォワードMEを共有設定**（全口座を可視化）
3. **夫婦それぞれのNISA口座を開設**（楽天証券 or SBI証券）

夫婦で資産形成を始めると、老後の安心感が大幅に変わります。まず一歩踏み出しましょう。
