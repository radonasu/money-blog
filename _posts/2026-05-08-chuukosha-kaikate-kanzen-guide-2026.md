## 中古車を買う前に決めること

### 予算を「総額」で決める

中古車の予算は**「車両本体価格」ではなく「乗り出し総額」**で考えるのが鉄則。

| 項目 | 目安金額 |
|------|---------|
| 車両本体価格 | 例: 100万円 |
| 諸費用（登録・手数料等） | 10〜15万円 |
| 自賠責・自動車税 | 3〜5万円 |
| 任意保険（初年度） | 5〜10万円 |
| 整備・点検・納車費用 | 5〜10万円 |
| **乗り出し総額** | **123〜140万円** |

**車両価格の20〜40%が諸費用**になるため、車両本体100万円なら総額は120〜140万円を見込む。

### 車種・グレードを決める

| 用途 | おすすめ車種カテゴリ |

| アウトドア | SUV（CX-5・フォレスター・ハリアー） |

**狙い目は3〜5年落ち・走行距離3〜5万km**。新車保証が残っている個体もあり、価格は新車の50〜70%。

## 優良な中古車の見分け方

### 修復歴車を避ける

**修復歴車**とは、骨格部分（フレーム・ピラー・ルーフ等）を修理または交換した車。事故車とほぼ同義で、走行性能・安全性に問題が出る可能性大。

- **販売店表示で「修復歴あり」と明記**されている個体は買わない
- 価格が相場より20〜30%安い場合は要注意
- 「修復歴なし」表示でも、隠蔽するケースがあるため第三者鑑定を活用

### 走行距離のチェック

| 年式 | 適正走行距離 |
|------|------------|
| 3年落ち | 3〜4.5万km |
| 5年落ち | 5〜7.5万km |
| 7年落ち | 7〜10.5万km |
| 10年落ち | 10〜15万km |

**目安: 1年1万〜1.5万km**。これより極端に少ない（年5,000km以下）または多い（年2万km超）は理由を確認。

### 内外装のチェックポイント

#### 外装

- ボンネット・ドア・フェンダーの**塗装の色違い**（事故修理の痕跡）
- パネルの**隙間の不自然さ**（事故修理の歪み）
- タイヤの**偏摩耗**（足回り異常の可能性）
- フロントガラスの**ひび・飛び石跡**

#### 内装

- シートの**へたり・破れ**（オーナーの使い方を反映）
- 天井の**シミ・汚れ**（雨漏り・タバコ歴）
- ペダル・ハンドルの**摩耗具合**（実走行距離との整合性）
- メーターの**改ざん痕跡**（数字の不自然さ）

#### エンジン・足回り

- エンジンルームの**油漏れ・水漏れ**
- バッテリーの**製造年**（2年以上前なら交換時期）
- マフラーの**錆・穴**
- 試乗時の**異音・振動**

**100万円以上の中古車を買うなら、第三者鑑定で1〜3万円かけても元が取れる**。

## 値引き交渉術【中古車でも10〜30万円安くなる】

### 交渉の鉄則

1. **複数店舗で見積もりを取る**（最低3店）
2. **「他店ではこの価格」と具体的に提示**
3. **諸費用の値引き**を狙う（車両価格より下げやすい）
4. **月末・3月決算期・9月中間決算期**を狙う
5. **下取り車がある場合は買取専門店と二重比較**

### 値引きが取れる項目

| 項目 | 値引き目安 |
|------|----------|
| 車両本体価格 | 5〜10万円（相場より下げにくい） |
| 諸費用パック | **5〜10万円**（最も下げやすい） |
| 整備・点検費用 | 1〜3万円 |
| オプション（カーナビ等） | 20〜30%引き |
| **合計値引き目安** | **10〜30万円** |

### 下取りより買取専門店

下取り価格は買取相場の60〜80%が一般的。**下取りは断り、買取専門店（ガリバー・ビッグモーター・カーセブン等）で別売り**が鉄則。

| サービス | 平均査定アップ額 |
|---------|--------------|
| カーセンサー一括査定 | +10〜30万円 |
| 楽天Carオークション | +15〜40万円 |
| ガリバーオート（買取） | +5〜20万円 |

## 中古車購入の必要書類

### 普通車（軽以外）

- **印鑑証明書**（発行から3ヶ月以内）
- **実印**
- **委任状**（販売店に名義変更を依頼）
- **自動車保管場所証明書（車庫証明）** ※軽自動車の一部地域は不要
- **住民票**（車検証の住所変更がある場合）

### 軽自動車

- **印鑑**（認印でOK）
- **住民票**（発行から3ヶ月以内）
- **自動車保管場所届出書**（一部地域のみ）

**車庫証明の取得**: 自宅から2km以内の駐車スペース確保。警察署で申請（手数料2,500〜3,000円）。

## 中古車購入後の維持費

### 年間維持費の目安

| 項目 | 軽自動車 | コンパクトカー | ミニバン |
|------|---------|--------------|---------|
| 自動車税 | 10,800円 | 30,500円 | 39,500円 |
| 自動車保険 | 35,000〜50,000円 | 40,000〜60,000円 | 50,000〜80,000円 |
| 車検費用（年換算） | 30,000〜40,000円 | 40,000〜60,000円 | 60,000〜80,000円 |
| ガソリン代（年1万km） | 70,000〜100,000円 | 100,000〜130,000円 | 150,000〜200,000円 |
| 駐車場代（地域差大） | 60,000〜240,000円 | 60,000〜240,000円 | 60,000〜300,000円 |
| **年間合計** | **約20〜45万円** | **約30〜55万円** | **約40〜75万円** |

**車両価格だけでなく、年間維持費30〜50万円を加算した「7年TCO（総保有コスト）」で判断**するのが賢い。

### 維持費を下げる5つの方法

1. **自動車保険はダイレクト型**（年3〜5万円節約）
2. **車検は楽天車検・ホリデー車検で予約**（5,000〜15,000円節約）
3. **タイヤは通販で買って取り付けだけ依頼**（1〜3万円節約）
4. **ガソリンは高還元クレカ + ENEOSカード**（年1〜2万円節約）
5. **駐車場は月極よりタイムズの定期利用**（地域による）

## まとめ — 中古車購入で失敗しないための5原則

2026年の中古車購入は以下の方針で：

1. **総額予算で考える** — 車両価格の20〜40%が諸費用
2. **3〜5年落ち・年式相応の走行距離**が狙い目
3. **修復歴なし・第三者鑑定**で安全性を確保
4. **複数店舗で見積もり比較 + 月末決算期**で10〜30万円値引き
5. **下取りせず買取専門店**で5〜40万円アップ

中古車は**新車より50〜70%の価格で同等の性能**が手に入る賢い選択肢。ただし買い方を間違えると修復歴車・ぼったくり店で大損するリスクも。**カーセンサー・グーネットで相場を把握 + 大手販売店で安心購入**が王道です。

中古車購入と合わせて、**自動車保険の見直し（年3〜5万円節約）・ガソリン代節約（年1〜2万円節約）**もセットで行えば、年間5〜10万円の固定費削減も実現できます。
