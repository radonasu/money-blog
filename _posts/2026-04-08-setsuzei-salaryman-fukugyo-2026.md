# 節税 サラリーマン 副業 2026【経費計上の裏技と確定申告の注意点完全ガイド】

副業収入が増えてきたとき「何が経費になるの？」「確定申告はどうすればいい？」「会社にバレない？」という不安を持つ方は多いです。2026年の最新情報をもとに、サラリーマン副業の節税と確定申告を完全解説します。

## 副業の確定申告が必要になる条件

まず基本から。副業収入がある場合、以下の条件で確定申告が必要です。

| 条件 | 確定申告の要否 |
|------|-------------|
| 副業の年間所得が20万円超 | **必要** |
| 副業の年間所得が20万円以下 | 不要（ただし住民税の申告は別途必要な場合あり） |
| 会社で年末調整済み + 副業所得20万以下 | 原則不要 |
| 医療費控除・住宅ローン控除がある場合 | 副業所得に関わらず申告が有利 |

**ポイント：「所得」とは「収入 − 経費」の金額。経費をしっかり計上することで課税対象を減らせます。**

## 在宅副業の「家事按分」：自宅経費の計上方法

副業を自宅でしている場合、家賃・光熱費の一部を経費にできます。

### 家賃の按分計算例

**例：家賃10万円・3LDK（全60㎡）・副業用書斎10㎡・週5日8時間副業**

- 面積按分：10㎡ ÷ 60㎡ = 約17%
- 時間按分（任意）：副業時間 / 総時間
- **計上できる家賃：10万円 × 17% = 約17,000円/月**

### 通信費・光熱費の按分

- インターネット：副業利用が多ければ50〜80%の範囲で計上
- 電気代：副業作業時間割合で按分（目安：20〜30%）

**注意：按分割合は「合理的な根拠」が必要。税務調査で聞かれる可能性があるため、メモ・記録を残しておく。**

## 経費にならないもの（NG事例）

副業と関係のない費用を経費にするのは脱税になります。

| NG例 | 理由 |
|------|------|
| プライベートの食事・飲み会 | 副業と無関係 |
| 家族への給与（実態なし） | みなし給与扱いになる |
| 趣味の書籍（副業無関係） | 副業関連のもののみ可 |
| プライベート旅行費 | 副業の出張でなければNG |
| スーツ・衣服（一般的なもの） | 個人使用と区分不明 |

## 副業バレを防ぐ：住民税「普通徴収」の申告方法

副業が会社にバレる最大の原因は「住民税の金額が増えること」です。

### 普通徴収の申請手順

**確定申告書の記入方法：**
1. 確定申告書（第二表）の「住民税・事業税に関する事項」欄を探す
2. 「給与以外の所得に係る住民税の徴収方法の選択」で **「自分で納付」（普通徴収）** を選択
3. これにより副業分の住民税は会社ではなく自宅に通知が届く

**重要：この申請をしないと、副業分の住民税が会社の給与から天引きされ、経理部門に気づかれる可能性があります。**

### e-Taxでの申告（2026年版）

e-Tax（マイナンバーカード利用）なら：
- スマートフォンだけで申告完了
- 還付金が2〜3週間で振込（紙申告の1〜2ヶ月より大幅に早い）
- 24時間365日申告可能

## 青色申告 vs 白色申告：副業でどちらを選ぶべきか

副業が「事業所得」として認められる場合（継続的・反復的に行っている場合）、青色申告を選ぶと大きな節税メリットがあります。

| 比較項目 | 青色申告（65万円控除） | 白色申告 |
|---------|-------------------|--------|
| 控除額 | 65万円（e-Tax利用）または55万円 | 0円 |
| 帳簿の義務 | 複式簿記（難しい） | 単式で可 |
| 節税効果（所得税20%の場合） | 約13万円節税 | なし |
| 対応ソフト | 青色申告ソフト推奨（freee等） | 簡易で可 |
| 赤字の繰り越し | 3年間可能 | 不可 |

**副業の年間所得が50万円を超えるなら青色申告が断然お得。freeeやマネーフォワードを使えば帳簿管理が大幅に楽になります。**

## 副業×節税のよくある質問

**Q: 副業で20万円以下なら何もしなくていい？**
A: 確定申告は不要ですが、住民税の申告は市区町村に必要な場合があります。忘れると後から追徴課税される可能性があるため、地元の市区町村の窓口に確認を。

**Q: 現金払いで領収書をもらえない場合の経費処理は？**
A: メモ帳や支出管理アプリで「いつ・どこで・何のために・いくら」を記録しておきましょう。金額が少額（5,000円未満）であれば、メモ書きでも認められるケースがほとんどです。

**Q: 副業が赤字になった場合、給与所得と損益通算できる？**
A: 2022年から「事業所得」と認められない場合は損益通算できなくなっています。副業が「業務的に継続している」ことが認められれば事業所得として損益通算が可能です。

## まとめ：副業節税の3ステップ

1. **経費を漏れなく記録する**：領収書・レシートはすべて保管。デジタル化（スキャン）も有効
2. **青色申告を検討する**：年間所得50万円超なら65万円控除で大きく節税
3. **住民税の普通徴収を申請する**：確定申告書で「自分で納付」を選択するだけ

副業節税を効率化するには、**マネーフォワードやfreeeで帳簿を自動化**することが最も時間対効果が高い方法です。
