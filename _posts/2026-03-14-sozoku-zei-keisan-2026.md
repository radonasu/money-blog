# 相続税 計算方法 2026【基礎控除・節税対策・税理士選びの完全ガイド】

「うちは相続税なんて関係ない」と思っていませんか？実は**相続税の課税対象者は近年増加しており、都市部では不動産だけで基礎控除を超えるケースが増えています**。

本記事では、相続税の計算方法を図解でわかりやすく解説し、今すぐできる節税対策まで完全網羅します。

---

## 相続税がかかる人の割合は？

- 2023年の相続税課税割合: **約9.9%**（約10人に1人）
- 2015年の税制改正で基礎控除が縮小され、課税対象が拡大
- **東京都では約16%以上**が課税対象（不動産価格が高いため）

「資産家でなくても相続税がかかる時代」になっています。

---

## 相続税の基礎控除の計算式

```
基礎控除額 = 3,000万円 + （600万円 × 法定相続人の数）
```

### 具体例

| 法定相続人 | 基礎控除額 | 課税される遺産の目安 |
|-----------|-----------|-------------------|
| 1人（子1人） | 3,600万円 | 3,600万円超で課税 |
| 2人（配偶者+子1人） | 4,200万円 | 4,200万円超で課税 |
| 3人（配偶者+子2人） | 4,800万円 | 4,800万円超で課税 |
| 4人（配偶者+子3人） | 5,400万円 | 5,400万円超で課税 |

**遺産総額が基礎控除以下なら、相続税はゼロ**です。

---

## 相続税の計算ステップ（図解）

### STEP1: 遺産総額を把握する

相続財産に含まれるもの:
- 不動産（土地・建物）
- 現金・預貯金
- 有価証券（株式・投資信託）
- 生命保険金（一部）
- 退職金（一部）
- 車・貴金属・美術品など

### STEP2: 債務・葬儀費用を差し引く

- 借入金（住宅ローン残債など）
- 葬儀費用（実際にかかった費用）
- 未払い税金・医療費

### STEP3: 課税遺産総額を計算する

```
課税遺産総額 = 遺産総額 - 基礎控除額
```

### STEP4: 法定相続分で按分して税額を計算

| 課税遺産総額 | 税率 | 控除額 |
|------------|------|--------|
| 1,000万円以下 | 10% | - |
| 3,000万円以下 | 15% | 50万円 |
| 5,000万円以下 | 20% | 200万円 |
| 1億円以下 | 30% | 700万円 |
| 2億円以下 | 40% | 1,700万円 |
| 3億円以下 | 45% | 2,700万円 |
| 6億円以下 | 50% | 4,200万円 |
| 6億円超 | 55% | 7,200万円 |

### STEP5: 配偶者控除などを適用して最終税額を算出

---

## 具体的なシミュレーション

### 事例: 遺産6,000万円・相続人は配偶者と子1人（計2人）

1. 基礎控除: 3,000万円 + 600万円×2 = **4,200万円**
2. 課税遺産総額: 6,000万円 - 4,200万円 = **1,800万円**
3. 法定相続分（1/2ずつ）: 各900万円
4. 各人の相続税: 900万円×15% - 50万円 = **85,000円**
5. 合計相続税: 85,000円×2 = **170,000円**
6. 配偶者控除（1億6,000万円まで非課税）を適用すると → 子だけに課税 = **85,000円**

## 今すぐできる相続税節税対策5選

### ①年間110万円の贈与（暦年贈与）

贈与税の基礎控除（110万円）を活用して、毎年110万円まで非課税で子や孫に財産を移せます。

- **効果**: 10年間で1,100万円の財産移転（相続税の計算から外れる）
- **注意**: 2024年改正で相続前3年→7年以内の贈与が相続財産に加算されるようになった（経過措置あり）

### ②生命保険の非課税枠を活用

生命保険の死亡保険金は「500万円×法定相続人数」まで非課税。

- 相続人2人 → 1,000万円まで非課税
- 相続人3人 → 1,500万円まで非課税

現金を生命保険に変えるだけで大きな節税効果。

### ③不動産への資産変換

現金1億円より不動産1億円の方が相続税評価額が低くなる（土地は路線価、建物は固定資産税評価額で評価）。

- 土地: 時価の約80%で評価
- 建物: 時価の約60〜70%で評価

### ④小規模宅地等の特例を活用

被相続人の自宅敷地を相続する場合、**最大330㎡まで評価額が80%減額**されます。

例: 評価額4,000万円の土地 → 800万円に減額（3,200万円分節税！）

### ⑤相続時精算課税制度の活用

2023年改正で改良された相続時精算課税制度では、**年110万円の控除が新設**されました。
- 60歳以上の親・祖父母から18歳以上の子・孫への贈与に使える
- 基礎控除110万円+2,500万円の特別控除

## 相続税の申告・納付期限

**相続の開始を知った翌日から10ヶ月以内**に申告・納付が必要です。

期限を過ぎると加算税・延滞税が発生するため要注意。複雑な財産がある場合は、相続開始後すぐに税理士に相談することをおすすめします。

---

## 税理士に依頼すべきケース

| ケース | 自分で手続き | 税理士依頼 |
|--------|------------|-----------|
| 遺産が基礎控除以下 | ○可能 | △不要なことが多い |
| 不動産なし・シンプルな財産 | △難しいが可能 | ○推奨 |
| 不動産あり | ✕難しい | ○必須レベル |
| 相続人間でもめている | ✕不可 | ○必須（弁護士も） |
| 二次相続対策も含めて | ✕難しい | ○強く推奨 |

### 税理士費用の目安

| 遺産総額 | 報酬の目安 |
|---------|-----------|
| 〜5,000万円 | 15〜30万円 |
| 5,000万〜1億円 | 30〜60万円 |
| 1〜3億円 | 60〜150万円 |

**相続税の申告ミスによるペナルティ（延滞税・加算税）と比べると、税理士費用は安い投資**です。特に不動産を含む相続は必ず専門家に依頼しましょう。
