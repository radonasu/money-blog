## 年収別節税シミュレーション：あなたは何万円損している？

会社員の多くは「税金は会社任せ」で損をしています。ふるさと納税・iDeCo・新NISAを正しく組み合わせれば、**年間10万〜50万円以上**の節税が可能です。

この記事では年収400万・500万・600万・800万円のケース別に、最も効果的な節税プランをシミュレーションします。

## 会社員が使える主な節税制度

| 節税制度 | 節税効果 | 手間 |
|---------|---------|------|
| ふるさと納税 | 年収の1〜3%相当 | 低 |
| iDeCo | 掛金×所得税率 | 低 |
| 生命保険料控除 | 最大4万円控除 | 低 |
| 住宅ローン控除 | 借入残高×0.7% | なし（自動） |
| 医療費控除 | 10万円超過分×税率 | 中（確定申告要） |
| 新NISA | 運用益非課税 | 低 |

## ■ 年収400万円の最強節税プラン

**前提条件**: 独身・会社員、所得税率10%、住民税率10%

| 制度 | 設定額 | 節税額 |
|-----|--------|-------|
| ふるさと納税 | 上限約3万円 | 約3万円控除（実質2,000円負担） |
| iDeCo | 月1.2万円（年14.4万円） | **約2.9万円節税** |
| 生命保険料控除 | 年8万円の保険料 | **約0.8万円節税** |
| **合計節税額** | | **約6.7万円/年** |

毎月5,600円節税できる計算です。iDeCoは老後資産にもなるため、実質的な恩恵はさらに大きくなります。

**年収400万円向けのポイント**:
- ふるさと納税はまず最優先で実施（2,000円の負担で年3万円分の返礼品をもらえる）
- iDeCoは月1万2千円（会社員の限度額の5割）から始めてOK
- 節税した分は新NISAに回すのが王道

## ■ 年収500万円の最強節税プラン

**前提条件**: 配偶者あり・子1人、所得税率20%、実質手取り約390万円

| 制度 | 設定額 | 節税額 |
|-----|--------|-------|
| ふるさと納税 | 上限約6万円 | 約6万円控除 |
| iDeCo | 月2.3万円（年27.6万円） | **約5.5万円節税** |
| 医療費控除（子の医療費等） | 年15万円の医療費 | **約1.0万円節税** |
| **合計節税額** | | **約12.5万円/年** |

**毎月1万円以上の節税効果**。年間12万5千円は家族旅行1回分に相当します。

**年収500万円向けのポイント**:
- iDeCoをフル活用（月2.3万円が会社員の上限）すると節税効果が最大化
- 子どもの医療費が年10万円超えたら確定申告で医療費控除を申請
- 住宅ローンがあれば住宅ローン控除も別途適用可能

---

## ■ 年収600万円の最強節税プラン

**前提条件**: 会社員、所得税率20%、実質手取り約455万円

| 制度 | 設定額 | 節税額 |
|-----|--------|-------|
| ふるさと納税 | 上限約7.7万円 | 約7.7万円控除 |
| iDeCo | 月2.3万円（年27.6万円） | **約5.5万円節税** |
| 新NISA（運用益非課税） | 年100万円投資・年10%利益 | **10万円の税金が消滅** |
| **合計節税・利益保護額** | | **約23万円/年** |

年収600万円は「節税の旨味が最も大きいゾーン」です。iDeCoをフル活用し、新NISAで運用益を非課税化することで、トータルで月約2万円の節税効果が生まれます。

**年収600万円向けのポイント**:
- ふるさと納税の上限額が一気に上がる（約7.7万円）
- 新NISAの成長投資枠（年240万円）も活用開始を検討
- 住宅購入を検討中なら住宅ローン控除（最大年35万円）の計算も忘れずに

## ■ 年収800万円の最強節税プラン

**前提条件**: 会社員、所得税率23%、実質手取り約572万円

| 制度 | 設定額 | 節税額 |
|-----|--------|-------|
| ふるさと納税 | 上限約13万円 | 約13万円控除 |
| iDeCo | 月2.3万円（年27.6万円） | **約6.4万円節税** |
| 小規模企業共済（副業あり） | 月7万円（年84万円） | **約19.3万円節税** |
| 生命保険料控除 | 最大4万円控除 | **約0.9万円節税** |
| **合計節税額** | | **約39.6万円/年** |

**年収800万円のキーは「小規模企業共済」**。副業や個人事業収入がある場合に使える制度で、最大月7万円（年84万円）の掛金が全額所得控除になります。

**年収800万円向けのポイント**:
- 副業・フリーランス収入があれば小規模企業共済が最強の節税ツール
- ふるさと納税の上限が約13万円と大幅に増える
- 将来の相続対策として生前贈与（年110万円非課税）の検討も始める時期

## 節税を始めるための証券口座開設

iDeCo・新NISAを始めるには証券口座が必要です。

| 証券会社 | 特徴 | こんな人向け |
|---------|------|------------|
| **SBI証券** | iDeCo取扱機関No.1・手数料最安 | 手数料を最小化したい |
| **楽天証券** | 楽天カード積立でポイント1%還元 | 楽天ユーザー |
| **マネックス証券** | カード積立還元率1.1%（業界最高） | ポイント還元率重視 |

| 500万円 | 約12.5万円 | 約1.0万円 |

年収が上がるほど節税効果は大きくなります。「やらない理由はない」レベルのリターンです。

まず今日できることから始めましょう:
1. **ふるさと納税**: さとふる・ふるなびで今すぐ申込み可能
2. **iDeCo**: SBI証券か楽天証券で口座開設（最短5分）
3. **新NISA**: iDeCoと同じ口座で設定可能
